# Farm Calculator 🌱

A Python Jupyter calculator with English and Kannada support.

## Features
- Crop revenue, expenses, profit and break-even price
- Seed requirements from planting area and spacing
- Nursery production costs and selling prices
- Market comparison after commission and transport

## How to run
1. Download farm_calculator.ipynb.
2. Open it in Jupyter Notebook.
3. Run the ipywidgets installation cell.
4. Run the calculator cell.
5. Choose a language and calculator, enter values, and calculate.

## Limitations
Results are planning estimates.
This version runs in Jupyter, not as an Android app.
Google Sheets saving is planned.
